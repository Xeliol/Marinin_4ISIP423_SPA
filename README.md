## Описание проекта
Данный проект представляет собой **WPF** приложение, разработанное в рамках прохождения учебной практики. Система автоматизирует внутренние бизнес-процессы предприятия (включая работу менеджеров, мастеров и администраторов), предоставляя инструменты для управления учетными записями, услугами, заказами, расписанием записей и генерацией динамической отчетности.

### Основные компоненты и модули проекта:

*   **Управление пользователями и правами доступа (`Pages/`)**:
    *   `LoginPage` — авторизация пользователей в системе с разделением ролей (Администратор, Менеджер, Мастер, Клиент).
    *   `RegisterPage` / `AddUserPage` — регистрация новых пользователей и добавление их администратором.
    *   `UsersTabPage` — панель управления пользователями (просмотр, редактирование, удаление).
*   **Управление каталогом товаров и услуг**:
    *   `ProductsPage` / `AddProductPage` — каталог товаров, добавление/редактирование позиций.
    *   `ProductTypesTabPage` — классификатор категорий и типов товаров.
    *   `ServicesTabPage` / `AddServicePage` — реестр оказываемых услуг.
    *   `ServiceTypesTabPage` / `AddServiceTypePage` — управление категориями услуг.
*   **Управление заказами и записями (Корзина и Расписание)**:
    *   `CartPage` / `Cart.cs` — модуль корзины для оформления заказов клиентов.
    *   `PaymentWindow` — диалоговое окно эмуляции оплаты и выбора типа платежа.
    *   `AddAppointmentPage` / `AppointmentsTabPage` — система записи клиентов на определенное время к мастерам.
*   **Информационно-аналитический блок (Отчеты)**:
    *   `ReportsPage` — общая панель аналитики.
    *   `OrdersDynamicReportPage` — динамический отчет по заказам с фильтрацией по датам/стоимости.
    *   `ProductTypesReportPage` — отчет по категориям продукции и популярности.
    *   `ServicesPopularityPage` — аналитика востребованности услуг.
    *   `MastersLoadPage` — отчет по занятости и нагрузке мастеров.

## Реализованный функционал

1.  **Навигация:** Реализован бесшовный переход между экранными формами без открытия новых окон (за исключением модальных окон оплаты/смены пароля).
2.  **ORM (Object-Relational Mapping):** Взаимодействие с базой данных реализовано через **Entity Framework** (`Model1.edmx`), что обеспечивает безопасность транзакций и типизацию данных.
3.  **Кастомизация интерфейса (Темы оформления):** Внедрена поддержка стилей интерфейса (файлы `Dictionary.xaml` и `DictionaryDark.xaml` для светлой и темной тем).
4.  **Валидация и безопасность:**
    *   Разделение интерфейса в зависимости от роли вошедшего пользователя (`AdminPage`, `ManagerPage`, `MasterPage`).
    *   Функционал смены и сброса пароля (`ChangePassPage`).

## Запуск и развертывание

### Системные требования:
*   Операционная система Windows 10/11
*   IDE Microsoft Visual Studio 2022 (с установленной рабочей нагрузкой "Разработка настольных приложений .NET")
*   .NET Framework 4.7.2 или выше
*   Установленная СУБД MS SQL Server / LocalDB

### Шаги для запуска:
1. Клонируйте репозиторий с проектом.
2. Откройте файл решения `Marinin_4ISIP423_SPA.sln` в Visual Studio.
3. Убедитесь, что строка подключения (Connection String) в файле `App.config` соответствует вашей локальной конфигурации базы данных.
4. Выполните восстановление пакетов NuGet (будет скачан `EntityFramework`).
5. Нажмите клавишу **F5** для сборки и запуска приложения.
